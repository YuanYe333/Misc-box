# MiscBox 第三方测试方案

> 给外部 AI / 测试者的完整说明。目标不是「跑一遍看看」，而是**独立复现结论**并找出我没发现的问题。

## 0. 给测试者的话（请先读）

这个项目是 Windows 上的 CTF 工具集合，仓库只放框架、文档和下载脚本，不放二进制。

**你的任务是挑错，不是确认它能用。** 以下是我已经自测过的结论，请独立验证；如果对不上，那就是有价值的发现：

- 仓库 20 个跟踪文件、7 次提交、无二进制
- 7 个分类文档行数：480 / 187 / 381 / 482 / 300 / 319 / 200
- 自检脚本在我机器上 `pass=29 fail=0 warn=2`
- 干净 clone 后 `setup.ps1` 报 15 项缺失（预期，工具还没下载）

**已知问题（不用重复报告，除非你能给出更好的解法）：**

1. `tools-manifest.json` 里 16 个工具只有 3 个填了 `sha256`（7zip / exiftool / john）。hashcat、nmap 上游只发 PGP `.asc` 不发稳定哈希，我没有编造。
2. 7 个工具必须手动装：Npcap（内核驱动）、Wireshark、ARCHPR（商业软件）、pngcheck、foremost（上游只发源码）、stegsolve、binwalk。
3. `gen_docs.py` 已经和现有文档脱节——直接重新生成会丢掉手写章节。这是已知隐患。
4. 仓库没有 CI，所有验证都是手工的。

## 2. 自动化自检（主要手段）

我准备了一个只读自检脚本，**放在附件 `miscbox-selftest.ps1`**。把它复制到 clone 出来的仓库里任意位置（推荐 `scripts\`），然后：

```powershell
# 静态检查，不执行 setup
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\miscbox-selftest.ps1

# 加上环境自检
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\miscbox-selftest.ps1 -RunSetup

# 也可以指定任意仓库路径
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\miscbox-selftest.ps1 -RepoRoot D:\某处\miscbox
```

它检查 7 组共 29 项：

| 组 | 检查内容 |
| --- | --- |
| 1 | git 跟踪文件数、有无二进制、工作区是否干净、有无未跟踪文件 |
| 2 | 所有 `.ps1` 是否纯 ASCII（PS 5.1 无 BOM 时按 GBK 读，中文会导致解析失败） |
| 3 | `tools.json` 能否解析、20 个工具 / 7 分类、必需字段、id 唯一性 |
| 4 | `tools-manifest.json` 能否解析、9 auto / 7 manual、auto 有 url、manual 有理由、sha256 覆盖率 |
| 5 | 全库扫描占位符与作者路径（`YOUR-NAME`、`<you>`、`websec`、`Users\1` 等） |
| 6 | 7 个分类目录、每个都有 README、行数合理 |
| 7 | 可选：跑 `setup.ps1`，读 `env-report.json` 的 summary |

**预期输出**（干净 clone + 脚本放在 `scripts\`，带 `-RunSetup`）：

```
pass=28  fail=0  warn=4
RESULT: no failures
```

其中 4 条 WARN 是预期的：`sha256` 覆盖率、工作区有 1 个未提交改动（就是你放进去的测试脚本）、有未跟踪文件（同一个）、15 项缺失（工具未下载）。

**如果 `fail` 不为 0，请把完整输出贴回来。** 特别关注：

- 中文路径下第 1 组是否报 `Illegal characters in path`
- 第 2 组是否指出某个 `.ps1` 含非 ASCII 字节
- 第 5 组是否扫出任何作者路径

## 3. 手工验证（自检覆盖不到的部分）

自检只做静态检查，以下必须手工做。

### 3.1 文档真实性抽查

随机挑 3 个分类的 README，每条命令**实际敲一遍**，看是否与文档描述一致。重点：

```powershell
# 编码识别：CyberChef 是否真的能离线打开
# （这是单个 HTML 文件，双击即开，无需服务器）
dir D:\测试中文路径\miscbox\02-编码识别\CyberChef

# 流量分析：文档里关于 tshark 的说明
& 'C:\Program Files\Wireshark\tshark.exe' --version
```

**要找的问题：** 文档里写的路径/命令在没装工具的机器上是否会误导人？例如 `05-流量分析\README.md` 描述了 Npcap 安装后的验证步骤，但读者还没装 Npcap 时读到这段是什么感受？

### 3.2 下载脚本的行为（不实际下载）

```powershell
# 只看状态，不下载任何东西
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\bootstrap.ps1

# 看帮助，列出 16 个工具 id 和自动/手动标记
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\bootstrap.ps1 -Help
```

**要找的问题：**

- 状态输出是否清楚说明「缺什么、怎么补」？
- `-Help` 里的工具清单和 `tools-manifest.json` 是否一致？
- 有没有哪个 URL 已经 404（可以只做 HEAD 请求验证，不必下载）：

```powershell
# 从 manifest 里取 URL 逐个验证可达性
$man = Get-Content scripts\tools-manifest.json -Raw -Encoding UTF8 | ConvertFrom-Json
foreach ($t in $man.tools) {
    if ($t.auto -eq $true -and $t.url) {
        $r = & curl.exe -s -o NUL -w "%{http_code}" --ssl-no-revoke --max-time 20 -I $t.url
        Write-Host ("{0,-16} {1}" -f $t.id, $r)
    }
}
```

期望全部是 `200` 或 `302`。**如果哪个是 `404`，那是我上次没测到，属于真 bug。**

### 3.3 GUI 启动器

```powershell
# 需要 Python 3.10+，官方安装包（要带 tkinter）
python -c "import tkinter; print('tkinter OK')"
python -X utf8 _box\app\gui.py
```

**要找的问题：**

- 窗口标题是否为 `杂项工具箱 · MiscBox`
- 工具卡片是否都显示（缺工具的应显示为红色/不可用，**不应该崩溃**）
- 点击一个「文件不存在」的工具，是否给出友好提示而不是抛异常
- 搜索框输入「隐写」「压缩包」是否能搜到
- 中文宽度对齐是否错位（我用 `_vis_len` 处理 CJK 宽度，可能有边界情况）

### 3.3.1 运行面板（拖放 → 运行 → 看输出）

选中一个可运行的工具（比如「隐写 → pngcheck 套件」），右侧默认就是「▶ 运行」页。

**要找的问题：**

- **拖放能不能用**：从资源管理器把一个 PNG 拖进窗口，拖放区是否显示文件名
  （拖放用的是原生 `WM_DROPFILES`，不是第三方包；如果拖不进去请告诉我 Windows 版本）
- 没选工具就拖文件，是否提示「先选一个工具」而不是乱跑
- 在「📖 说明」页拖文件，是否自动切回「▶ 运行」页
- 点「▶ 运行」后输出是否**实时**刷出来（不是跑完才一次性出现）
- 长输出会不会卡住界面；点「■ 停止」能否真的停下
- 跑完后面板下方是否列出产出文件，点「📂 输出目录」能否打开
- 带「运行方式」下拉的工具，切换预设后命令行预览是否跟着变
- 需要填参数的工具（如 CRC32 爆破的 `{crc}`/`{len}`），输入框是否出现

**已知限制（不算 bug）：**

- 文件夹拖放不支持，只收文件
- 一次只能跑一个任务，跑着的时候再点会提示等待
- 个别工具（foremost 扫大文件、hashcat 跑字典）要等一会才有第一行输出

### 3.4 一个真实的下载（可选，最耗时）

挑体积最小的工具跑完整流程，验证下载→解压→校验→可用：

```powershell
# exiftool 约 13 MB，是清单里较小的
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\bootstrap.ps1 -Only exiftool -Yes
```

**预期：** 下载后 SHA256 校验通过（exiftool 是 3 个已填哈希的工具之一），解压到 `03-隐写\CTF-tools\exiftool\`，`exiftool.exe -ver` 输出 `13.59`。

**要找的问题：**

- 中文路径下解压是否正常
- 已存在同名文件时是否覆盖/跳过（脚本设计是复用已下载的包）
- 中断后重跑是否能续传（可以中途 Ctrl+C 再跑一次）

**特别欢迎指出的：**

## 5. 安全与合规审查

这个项目容易被误认为「黑客工具包」，请检查文档是否守住了边界：

- `README.md` 和 `LICENSE` 是否明确限定「仅授权测试」？
- `07-OSINT\README.md` 的 theHarvester 用法是否提示了合规风险？
- 是否有任何工具默认执行破坏性操作？
- `bootstrap.ps1` 是否真的**不写注册表、不改系统 PATH**？（唯一的例外是 Npcap 驱动，文档是否说清了？）

**验证方法：** 在 `bootstrap.ps1` 里搜 `New-ItemProperty`、`reg add`、`[Environment]::SetEnvironmentVariable`、`setx`，应该一个都没有。
